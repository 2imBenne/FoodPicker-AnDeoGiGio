## 🌟 Điểm Nổi Bật (Key Features)

### 📦 1. Kho Hòm Đa Dạng (5 Phân Loại Chuyên Biệt)

Không chỉ dừng lại ở bữa ăn chính, ứng dụng cung cấp kho hòm đầy đủ cho mọi nhu cầu ăn uống & giải trí của Gen Z:

- 🍖 **Hòm No Nê (Bữa Chính Chắc Bụng)**: Cơm, phở, bún, lẩu... Hỗ trợ chuyển đổi linh hoạt giữa chế độ **Mặn** và **Chay**.
- 🍟 **Hòm Ăn Vặt (Cứu Đói Xế Chiều)**: Bánh tráng trộn, xiên que, nem chua rán, chân gà sả tắc, hột vịt lộn, tokbokki...
- 🧋 **Hòm Trà Sữa & Đồ Uống (Giải Khát Tỉnh Táo)**: Trà sữa trân châu, cà phê muối, trà vải lài, bạc xỉu, trà chanh giã tay...
- 🍨 **Hòm Tráng Miệng (Đồ Ngọt Thăng Hoa)**: Bingsu, chè khúc bạch, tàu hũ trân châu, bánh flan, kem, bánh crepe sầu riêng...
- 🗺️ **Hòm Địa Điểm (Đi Đâu Hôm Nay?)**: Các tụ điểm hẹn hò, vui chơi giải trí (Công viên, xem phim, photobooth, workshop làm đồ thủ công, tô tượng, escape room, bowling, billiards, net gaming, picnic...).

---

### 🎯 2. Trải Nghiệm Mở Hòm CS2 Chân Thực (Authentic CS2 Reel)

- **Thuật toán Newton-Raphson Cubic Bezier (`ease(0.12, 0.78, 0.18, 1.0)`)**: Mô phỏng hoàn hảo vật lý dải cuộn của CS2 — bứt tốc cực mạnh lúc đầu, giảm tốc mượt mà và bò chậm dần về đích.
- **Hệ thống âm thanh cơ học (Web Audio API)**:
  - Tiếng rumble nền dồn dập khi dải cuộn quay tốc độ cao.
  - Tiếng tick cơ học nhịp nhàng khi từng thẻ lướt qua vạch kim chỉ.
  - Fanfare hân hoan khi trúng thưởng và hiệu ứng âm thanh hoàng kim khi nổ Vàng.
- **Cơ chế "Near Miss" kịch tính**: Tỉ lệ kim dừng sát vách (±1 thẻ) cạnh thẻ Vàng Secret, tạo cảm giác tim đập thình thịch và tiếc nuối suýt trúng như mở hòm thật.

---

### 👑 3. Hệ Thống Vàng Secret Siêu Hiếm (★ Special Rare Items)

- **Tỉ lệ nổ Vàng chuẩn độ hiếm Dao/Găng tay (1.0%)**: Trung bình ~1/100 lượt quay, đảm bảo độ xa xỉ và danh giá.
- **Phần thưởng xa xỉ theo từng hòm**:
  - **Hòm Bữa Chính (Mặn)**: ★ Bò Wagyu A5 Dát Vàng ★, ★ Cua Hoàng Đế King Crab Sốt Bơ Tỏi ★, ★ Tôm Hùm Alaska Nướng Phô Mai ★, ★ Omakase Sushi Thượng Hạng ★, ★ Buffet Haidilao VIP ★.
  - **Hòm Bữa Chính (Chay)**: ★ Buffet Chay Hoàng Gia ★, ★ Lẩu Nấm Matsutake ★, ★ Yến Sào Đông Trùng Hạ Thảo ★, ★ Thố Cơm Niêu Bào Ngư Chay ★.
  - **Hòm Ăn Vặt**: ★ Đại Tiệc Xiên Bẩn Không Đáy ★, ★ Mâm Bánh Tráng Hoàng Gia Siêu To Khổng Lồ ★.
  - **Hòm Đồ Uống**: ★ Xô Trà Sữa 5 Lít Full Topping ★, ★ Cà Phê Chồn Tây Nguyên Thượng Phẩm ★.
  - **Hòm Tráng Miệng**: ★ Bingsu Tổ Yến Hoàng Gia ★, ★ Mâm Chè Cung Đình Huế 12 Món ★.
  - **Hòm Địa Điểm**: ★ Glamping / Cắm Trại Sang Chảnh ★, ★ Du Lịch Bí Ẩn 1 Ngày ★, ★ Du Lịch Dài Ngày ★.

---

### 📍 4. Tích Hợp Tìm Kiếm Google Maps Thông Minh

- Sau khi vòng quay dừng lại, người dùng có thể bấm trực tiếp vào nút **"TÌM QUÁN ĂN GẦN ĐÂY"** hoặc **"TÌM ĐỊA ĐIỂM GẦN ĐÂY"**.
- Tự động mở Google Maps với bộ lọc sắp xếp ưu tiên theo **khoảng cách gần nhất** (`sort by distance`).

---

### ✨ 5. Đồ Họa & Hiệu Ứng Sống Động

- **Particle Canvas**: Nền không gian vũ trụ với các hạt bụi sao chuyển động tương tác.
- **Confetti Cannon**: Pháo hoa giấy bùng nổ khi chiến thắng; riêng Vàng Secret được trang bị hiệu ứng pháo vàng kim rực rỡ toàn màn hình.
- **Responsive 100%**: Tối ưu hiển thị mượt mà trên Desktop, Máy tính bảng và Điện thoại di động.

## 🏗️ Cấu Trúc Mã Nguồn (Project Structure)

Dữ liệu được tổ chức tách bạch theo danh mục chuẩn nguyên lý **Single Responsibility Principle (SRP)**:

```text
FoodPicker-AnDeoGiGio/
├── public/
│   ├── favicon.png        # Icon bát mì dấu hỏi độc quyền trên tab
│   ├── logo.png           # Logo tài nguyên ứng dụng
│   └── ...
├── src/
│   ├── components/
│   │   ├── CaseSelector.jsx    # Màn hình chọn hòm (Armory grid)
│   │   ├── ConfettiCanvas.jsx  # Hiệu ứng pháo giấy ăn mừng
│   │   ├── Controls.jsx        # Nút quay & Toggle Chay/Mặn
│   │   ├── ItemGallery.jsx     # Lưới hiển thị các vật phẩm trong hòm
│   │   ├── ParticleCanvas.jsx  # Hiệu ứng hạt nền ambient
│   │   ├── Reel.jsx            # Vòng quay CS2 Reel & thuật toán vật lý
│   │   └── ResultModal.jsx     # Modal hiển thị kết quả & link Google Maps
│   ├── data/
│   │   ├── cases.js            # Cấu hình 5 hòm (CASES_CONFIG) & hàm getRandomSecretGold
│   │   ├── constants.js        # Bảng màu độ hiếm, thẻ vàng mẫu, formatPrice
│   │   ├── desserts.js         # Dữ liệu Hòm Tráng Miệng
│   │   ├── drinks.js           # Dữ liệu Hòm Đồ Uống
│   │   ├── mainMeals.js        # Dữ liệu Hòm Bữa Chính (Mặn & Chay)
│   │   ├── places.js           # Dữ liệu Hòm Địa Điểm Đi Chơi
│   │   ├── snacks.js           # Dữ liệu Hòm Ăn Vặt
│   │   ├── index.js            # Central Hub — Re-export toàn bộ data
│   │   └── foods.js            # Lớp tương thích ngược (Backward Compatibility)
│   ├── utils/
│   │   └── sound.js            # Sound Engine tổng hợp Web Audio API thuần
│   ├── App.jsx                 # Component chính điều phối flow
│   ├── index.css               # Design system, theme tối & animation
│   └── main.jsx                # Entry point ứng dụng
├── index.html                  # HTML template & cấu hình favicon
├── package.json
└── vite.config.js
```

## 🚀 Cài Đặt & Chạy Cục Bộ (Getting Started)

### Yêu Cầu Tiên Quyết

- [Node.js](https://nodejs.org/) (phiên bản 18.0.0 trở lên)
- Trình quản lý gói `npm` (đi kèm Node.js) hoặc `yarn` / `pnpm`

### Các Bước Cài Đặt

1. **Clone mã nguồn dự án:**
   ```bash
   git clone https://github.com/2imBenne/FoodPicker-AnDeoGiGio.git
   cd FoodPicker-AnDeoGiGio
   ```

2. **Cài đặt các gói phụ thuộc:**
   ```bash
   npm install
   ```

3. **Khởi chạy môi trường phát triển (Dev Server):**
   ```bash
   npm run dev
   ```
   *Mở trình duyệt tại địa chỉ `http://localhost:5173/` để trải nghiệm.*

4. **Đóng gói sản phẩm (Production Build):**
   ```bash
   npm run build
   ```

5. **Chạy thử bản đóng gói (Preview Build):**
   ```bash
   npm run preview
   ```
